# Product images

Add your product image files to this folder. The product catalog expects:

- `ceramic-mug.jpg`
- `woven-tote.jpg`
- `daily-notebook.jpg`
- `skincare-bottle.jpg`
- `glass-vase.jpg`
- `sunglasses.jpg`
- `journal.jpg`
- `bath-oil.jpg`

Each product can use more than one image. Add the additional files here and include their
paths in that product's `images` array in `app.js`; the order in the array is the display order.
